# Atomic Arig Lite

*This is a fork of [Atomic Arig](https://mods.factorio.com/mod/atomic-arig) by Hexthree, rewritten to be more similar to default Arig while fixing issues in the original mod.*

***This is a beta release, expect to run into bugs and backup your save before installing/updating.***

## What does this mod do?
- [🌐 Planetaris: Arig](https://mods.factorio.com/mod/planetaris-arig) is no longer locked behind Vulcanus, meaning it is now possible to visit it first. Some technologies and recipes have been adjusted to allow this.
- Uranium is no longer present on Nauvis, and instead is a unique resource of Arig. Uranium spawns naturally on the surface of Arig where it can be mined, or it can be acquired by sand sifting.
- The content from [Nuclear Science](https://mods.factorio.com/mod/atan-nuclear-science) has been merged with Arig's progression.
- All technologies that previously required compression science or nuclear science now require Arig's new science, densification science.
- The nuclear reactor, portable fission reactor, and Nuclear Science's atom forge now require Arig's heavy glass.
- Biolab, Atom Forge, and Supported Solar Panel technologies have been made multi-planet (can disable in mod startup settings).

---

### Compatibility
- [Maraxsis](https://mods.factorio.com/mod/maraxsis): Glass productivity affects glass panels. Startup setting to remove Arig science from glass productivity.
- [Paracelsin](https://mods.factorio.com/mod/Paracelsin): Concrete productivity affects new concrete from sandstone brick recipe.
